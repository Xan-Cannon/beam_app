# Project layout

This is a single-file web app served by GitHub Pages. Keep `index.html` at the
project root so GitHub Pages can find it. The project guidance, specification,
and prompt history also belong at the root:

- `AGENTS.md` — project instructions and file-placement rules.
- `spec.md` — project requirements and behavior.
- `prompts.md` — request and change history.
- `index.html` — the web app entry point.

Use the numbered folders for all other project files:

- `00_planning/` — notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the folder that matches its purpose. Keep the four
root-level files above at the root; do not put supporting files there.
